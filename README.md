# Document RAG Assistant | مساعد الوثائق الذكي

[English](#english) · [العربية](#العربية)

---

## English

A web app where you upload PDF files, ask questions about them, and get answers generated by an LLM **using only retrieved passages from your documents**. Every answer shows its sources (file + page + passage), and the system explicitly says so when the documents don't contain enough information.

### How it works (RAG pipeline)

```
PDF ──► extract text (pypdf, per page)
    ──► split into ~800-char chunks with 150-char overlap (page number kept)
    ──► embed chunks (sentence-transformers, multilingual, local)
    ──► store in ChromaDB (cosine similarity)

Question ──► embed ──► top-4 most similar chunks
         ──► gate 1: best similarity < MIN_SIMILARITY ?  ──► "not enough information" (LLM not called)
         ──► OpenAI chat model answers ONLY from those chunks, citing [1], [2]…
         ──► gate 2: model replies [[NO_ANSWER]] ?       ──► "not enough information"
         ──► answer + sources shown in the UI
```

| Requirement | Where |
|---|---|
| Upload PDFs & extract text | [backend/app/pdf_loader.py](backend/app/pdf_loader.py) |
| Chunking | [backend/app/chunking.py](backend/app/chunking.py) |
| Embeddings + vector DB | [backend/app/embeddings.py](backend/app/embeddings.py), [backend/app/vector_store.py](backend/app/vector_store.py) |
| Retrieval + LLM answer + "insufficient info" | [backend/app/rag.py](backend/app/rag.py) |
| REST API | [backend/app/main.py](backend/app/main.py) |
| Web UI (React) | [frontend/src/App.jsx](frontend/src/App.jsx) |
| Evaluation | [backend/scripts/evaluate.py](backend/scripts/evaluate.py), [backend/tests/](backend/tests/) |

### Tech stack

- **Backend:** Python, FastAPI, pypdf
- **Embeddings:** `paraphrase-multilingual-MiniLM-L12-v2` (sentence-transformers, runs locally, supports Arabic + English)
- **Vector DB:** ChromaDB (persistent, local)
- **LLM:** OpenAI API (default `gpt-4o-mini`)
- **Frontend:** React + Vite (English / Arabic with RTL)

### Setup

Requirements: Python 3.10+, Node 18+, an OpenAI API key.

```bash
# 1. Backend
cd backend
python -m venv .venv
.venv\Scripts\activate            # Windows  (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
cp .env.example .env              # then put your OPENAI_API_KEY inside .env
uvicorn app.main:app --reload --port 8000

# 2. Frontend (new terminal)
cd frontend
npm install
npm run dev                       # open http://localhost:5173
```

The first upload/question downloads the embedding model (~120 MB) once.

### Usage

1. Click **Upload PDF** (sample files are in [sample_docs/](sample_docs/)).
2. Ask a question in English or Arabic.
3. Read the answer; click a source chip to jump the PDF viewer to the cited page. Hover a chip to see the exact passage.
4. Ask something not in the files — you will get a "not enough information" reply with no sources.

### Testing & evaluation

```bash
cd backend
python -m scripts.make_sample_pdfs   # (re)generate the test PDFs in sample_docs/
pytest                               # unit tests: chunking + insufficient-info logic (no API key needed)
python -m scripts.evaluate           # end-to-end, needs OPENAI_API_KEY
```

`evaluate` indexes the sample PDFs and runs 5 answerable questions (checks the fact appears **and** the right file is cited) plus 3 unanswerable questions (English and Arabic) that must be declined.

### Configuration (`backend/.env`)

| Variable | Default | Meaning |
|---|---|---|
| `OPENAI_API_KEY` | – | Your OpenAI key (required) |
| `OPENAI_MODEL` | `gpt-4o-mini` | Chat model |
| `CHUNK_SIZE` / `CHUNK_OVERLAP` | 800 / 150 | Chunking in characters |
| `TOP_K` | 4 | Passages sent to the LLM |
| `MIN_SIMILARITY` | 0.30 | Below this the system declines without calling the LLM. Tune it with your own documents. |

### Live demo deployment (Docker)

The `Dockerfile` builds the React app and serves it together with the API from one FastAPI server on port 7860, and indexes the PDFs in `sample_docs/` on first start so visitors can ask right away.

- **Hugging Face Spaces:** create a Space with the **Docker** SDK, push this repository to it, and add `OPENAI_API_KEY` under *Settings → Variables and secrets* (as a **secret**).
- **Any Docker host:** `docker build -t rag . && docker run -p 7860:7860 -e OPENAI_API_KEY=sk-... rag`

Uploads are limited to 10 MB (`MAX_UPLOAD_MB`). Every visitor of a public demo shares the same document list and your OpenAI quota, so set a monthly usage limit in your OpenAI account.

### Limitations

- Scanned (image-only) PDFs have no extractable text and are rejected (no OCR).
- Each question is answered independently (no chat memory).
- The CORS origins are set for local development only.

## العربية

تطبيق ويب يرفع فيه المستخدم ملفات PDF ويسأل عنها، فيجيب نموذج لغوي **اعتماداً فقط على المقاطع المسترجعة من مستنداتك**. تظهر مع كل إجابة مصادرها (اسم الملف + الصفحة + المقطع)، ويصرّح النظام صراحةً عندما لا تكفي معلومات المستندات.

### كيف يعمل (مسار RAG)

```
PDF ──► استخراج النص (pypdf لكل صفحة)
    ──► تقسيمه إلى مقاطع ~800 حرف مع تداخل 150 حرف (مع حفظ رقم الصفحة)
    ──► إنشاء Embeddings (sentence-transformers متعدد اللغات، محلي)
    ──► تخزينها في ChromaDB (تشابه كوساين)

السؤال ──► Embedding ──► أقرب 4 مقاطع
       ──► بوابة 1: أعلى تشابه < MIN_SIMILARITY ؟  ──► "لا تتوفر معلومات كافية" (دون استدعاء النموذج)
       ──► نموذج OpenAI يجيب من المقاطع فقط مع الإشارة [1]، [2]…
       ──► بوابة 2: رد النموذج [[NO_ANSWER]] ؟    ──► "لا تتوفر معلومات كافية"
       ──► عرض الإجابة والمصادر في الواجهة
```

| المتطلب | مكانه |
|---|---|
| رفع PDF واستخراج النص | [backend/app/pdf_loader.py](backend/app/pdf_loader.py) |
| تقسيم النص | [backend/app/chunking.py](backend/app/chunking.py) |
| Embeddings وقاعدة المتجهات | [backend/app/embeddings.py](backend/app/embeddings.py)، [backend/app/vector_store.py](backend/app/vector_store.py) |
| الاسترجاع وتوليد الإجابة وعدم كفاية المعلومات | [backend/app/rag.py](backend/app/rag.py) |
| واجهة API | [backend/app/main.py](backend/app/main.py) |
| واجهة الويب (React) | [frontend/src/App.jsx](frontend/src/App.jsx) |
| التقييم | [backend/scripts/evaluate.py](backend/scripts/evaluate.py)، [backend/tests/](backend/tests/) |

### التقنيات

- **الخلفية:** Python وFastAPI وpypdf
- **Embeddings:** نموذج `paraphrase-multilingual-MiniLM-L12-v2` (يعمل محلياً ويدعم العربية والإنجليزية)
- **قاعدة المتجهات:** ChromaDB (محلية ودائمة)
- **النموذج اللغوي:** OpenAI API (الافتراضي `gpt-4o-mini`)
- **الواجهة:** React + Vite (عربي / إنجليزي مع دعم RTL)

### التثبيت والتشغيل

المتطلبات: Python 3.10+ وNode 18+ ومفتاح OpenAI API.

```bash
# 1. الخلفية
cd backend
python -m venv .venv
.venv\Scripts\activate            # ويندوز (لينكس/ماك: source .venv/bin/activate)
pip install -r requirements.txt
cp .env.example .env              # ثم ضعي OPENAI_API_KEY داخل ملف .env
uvicorn app.main:app --reload --port 8000

# 2. الواجهة (في نافذة طرفية جديدة)
cd frontend
npm install
npm run dev                       # افتحي http://localhost:5173
```

أول رفع أو سؤال يحمّل نموذج الـ Embeddings مرة واحدة (~120 ميجابايت).

### الاستخدام

1. اضغطي **رفع ملف PDF** (ملفات تجريبية في [sample_docs/](sample_docs/)).
2. اسألي بالعربية أو الإنجليزية.
3. اقرئي الإجابة، واضغطي على أي مصدر لينتقل عارض الـ PDF إلى الصفحة المذكورة. مرّري الفأرة على المصدر لرؤية المقطع نفسه.
4. اسألي عن شيء غير موجود في الملفات — سيظهر رد "لا تتوفر معلومات كافية" بدون مصادر.

### الاختبار والتقييم

```bash
cd backend
python -m scripts.make_sample_pdfs   # إعادة توليد ملفات PDF التجريبية في sample_docs/
pytest                               # اختبارات الوحدات: التقسيم ومنطق عدم كفاية المعلومات (بدون مفتاح)
python -m scripts.evaluate           # اختبار شامل، يحتاج OPENAI_API_KEY
```

يفهرس `evaluate` الملفات التجريبية ويطرح 5 أسئلة لها إجابة (يتحقق من ظهور المعلومة الصحيحة **ومن** ذكر الملف الصحيح)، و3 أسئلة بلا إجابة (بالعربية والإنجليزية) يجب رفضها.

### الإعدادات (`backend/.env`)

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `OPENAI_API_KEY` | – | مفتاح OpenAI (مطلوب) |
| `OPENAI_MODEL` | `gpt-4o-mini` | نموذج المحادثة |
| `CHUNK_SIZE` / `CHUNK_OVERLAP` | 800 / 150 | حجم المقطع والتداخل بالأحرف |
| `TOP_K` | 4 | عدد المقاطع المرسلة للنموذج |
| `MIN_SIMILARITY` | 0.30 | أقل من ذلك يرفض النظام دون استدعاء النموذج. اضبطيه حسب مستنداتك. |

### القيود

- ملفات PDF الممسوحة ضوئياً (صور فقط) لا تحتوي نصاً قابلاً للاستخراج وتُرفض (لا يوجد OCR).
- كل سؤال يُجاب باستقلال (لا توجد ذاكرة محادثة).
- إعدادات CORS مخصصة للتطوير المحلي فقط.
